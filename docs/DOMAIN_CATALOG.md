# Domain Catalog

| Domain | First-class capabilities | Shared engines used |
|---|---|---|
| Retail/Grocery | products, sales, purchases, debts, stores | finance, inventory, commerce, workflow |
| Dental Lab | cases, doctors, clinics, patients, messengers, production workflow | finance, inventory, documents, workflow |
| Clinic | patients, services, appointments, billing | finance, documents, workflow |
| Industrial | raw materials, production, finished goods, costing | inventory, finance, procurement, logistics |
| Company | organization, projects, expenses, customers, vendors | finance, CRM, workflow, documents |
| Mosque/Charity | donations, expenses, projects, approvals, custody | finance, workflow, audit, documents |
| Warehouse | receiving, storage, transfers, dispatch | inventory, logistics, workflow |

These are domain contracts, not separate applications.
